# legacy-survey-tool（舊系統功能現勘紀錄工具）

一個單檔、離線、隨開即用的「舊系統功能現勘紀錄」工具。到客戶端用他們的內部系統時，依畫面元素逐項記錄要翻新的功能，避免漏記；輸出可直接貼進後續的需求文件。

## 用途

- 現勘情境：在客戶端逐一盤點舊系統的頁面與功能，記錄每個畫面的使用資訊與畫面元件細節。
- 以樹狀「頁面／功能架構」組織內容，每個節點可掛畫面資訊欄位與多張元件卡；中間分類節點可空著只做分組。
- 選單路徑會依節點在樹上的祖先自動帶入，並隨匯出一起輸出。
- 產出可用 JSON（主力，可回頭載入）、Markdown（貼進需求文件），或「下載打包」成一個 zip（JSON＋Markdown＋依功能樹狀結構擺放的圖片）。
- 上傳截圖後，同一欄的圖片會依檔名自動自然排序（例如 image2 排在 image10 前）。

## 安裝／執行方式

本工具是單一自足的 HTML 檔（`legacy-survey-tool.html`），CSS 與 JS 全部內嵌，不連任何外部資源。

1. 取得 `legacy-survey-tool.html`。
2. 以瀏覽器直接雙擊開啟即可使用，無需安裝、無需連線、無建置流程。
3. 記錄完成後，用畫面上的「匯出 JSON」保存成果；下次可用「載入 JSON」接續。

## 注意事項

- 存檔以「匯出 JSON」為可靠方式。`localStorage` 自動暫存僅為盡力而為，在部分沙箱環境可能失效；截圖較多時也可能超出容量。
- 截圖上傳會等比縮到最寬 1600px、轉 JPEG（品質 0.72）後以 base64 存進 JSON。
- 「下載打包」會產生一個 zip：內含存檔 JSON（仍夾帶完整圖片，可直接載回）、帶圖片相對路徑的 Markdown，以及依功能樹狀階層放置的圖片檔（資料夾名＝節點名，同層或同資料夾同名會自動加序號）。zip 由內建的最小產生器製作，不需外部套件、可離線使用。
- 舊的平面 `screens` 格式在載入時會自動轉成頂層節點，可相容舊檔。
- 字體：連線時會向 Google Fonts 載入 Noto Sans TC；離線時改用本機已安裝的 Noto Sans TC，若未安裝則退用微軟正黑體與系統字體。這是唯一的對外連線，離線仍可正常使用，只是字體可能改用備援。
- 開發交接與尚未完成事項請見 `docs/handoff-notes.md`；需求與設計見 `docs/requirements.md`、`docs/design.md`。

## 測試

最小驗證放在 `tests/test.cjs`，不依賴任何套件。做法是抽出 HTML 內嵌的 `<script>`，以最小假 DOM 在 Node 載入後，對純邏輯函式（`normalize`、進度計算、`filled`、`moveNode`、`buildMarkdown` 等）做斷言。於工具資料夾內執行：

```
node tests/test.cjs
```

全部通過會回傳結束碼 0。視覺與互動手感仍須在真實瀏覽器驗收。

## 檔案

- `legacy-survey-tool.html`：工具本體（正式基準檔）。
- `docs/`：需求、設計與交接文件。
- `tests/`：最小可執行驗證。
