# 舊系統功能現勘紀錄工具 — 開發交接文件

> 給新對話接手用。建議把本檔與最新的 `legacy-survey-tool.html` 一起上傳，Claude 讀完即可接續開發。

## 1. 這是什麼

一個「舊系統功能現勘紀錄」工具。使用情境：到客戶端用他們的內部系統，確認要翻新的功能時，依畫面元素逐項記錄，避免漏記。輸出可貼進後續的需求文件。

## 2. 技術與檔案

- **單一自足的 HTML 檔**（`legacy-survey-tool.html`），CSS／JS 全部內嵌，不連任何外部資源，可離線用瀏覽器雙擊開啟。
- 純 vanilla JS，無框架、無建置流程。刻意如此以確保「單檔、離線、隨開即用」。
- **資料驅動畫面**：畫面上的每個欄位、每張元件卡，都是程式讀「定義物件」自動長出來的。

## 3. 資料模型（存在 `STATE`）

```
STATE = { meta:{client,date,note}, tree:[node], selected:nodeId, treeHidden:bool }
node  = { id, name, collapsed, children:[node], fields:{}, components:[comp] }
comp  = { id, type, label, collapsed, fields:{} }
```

- **樹狀「頁面／功能架構」**：每個節點可掛畫面細節（fields＋components），中間分類節點可空著只做分組。
- **選單路徑自動帶入**：某節點的選單路徑＝它在樹上一路往上的祖先名稱串接（以麵包屑顯示、並寫入匯出）。

## 4. 設定區（要擴充改這裡；在 `<script>` 最上方）

- **`SCREEN_FIELDS`**：節點層級（畫面資訊）欄位。目前有：使用頻率、使用角色與權限、用途說明、前置條件、相關法規／規範、已知問題／使用者抱怨、截圖。
  （已移除：功能名稱正式、畫面代號、選單路徑、進入點。）
- **`COMPONENT_TYPES`**：元件類型，每個含 `icon`（內嵌 SVG 路徑字串）與 `fields[]`。目前類型：下拉選單、輸入框、日期／區間、Radio（單選）、Checkbox（複選）、按鈕與動作、查詢邏輯、結果清單、報表匯出、錯誤與提示、自訂備註。
- **欄位型態（type）**：
  - `check`：是／否／待確認
  - `req`：是／否／選擇性／待確認；選「選擇性」會出現「必填條件」輸入框（條件值存在 `該key_cond`）
  - `choice`：自訂選項的單選按鈕，需在欄位加 `opts:[[值,顯示文字],…]`
  - `multi`：自訂選項的多選按鈕（值為陣列），同樣需 `opts`
  - `text` / `textarea`：文字（可加 `hint:'…'` 當提示文字）
  - `images`：多張截圖上傳（壓縮後存進存檔）

## 5. 已完成的功能（重點）

- 依元件類型自動展開檢查項目；每個元件用**內嵌 SVG icon** 區分（非用顏色）。
- **配色**（全走 CSS 變數，定義在 `:root`）：底 `#EEEADB`、主色 `#4C5760` 石板藍灰、完成/進度 `#93A8AC` 鼠尾草（深 `#6E8A90`）、強調 `#D7CEB2` 沙、中性線 `#A59E8C` 灰褐、文字 `#3F484F`、警示 `#A6604B`。
- 標題旁 logo：文件＋放大鏡的內嵌 SVG。
- **截圖**：上傳等比縮到最寬 1600px、轉 JPEG（品質 0.72）後以 base64 存進 JSON。
- **存檔**：localStorage 自動暫存（盡力而為、包 try/catch）＋ **JSON 匯出／載入（主力）** ＋ Markdown 匯出。
- **清空資料**：確認談窗＋可先匯出備份。
- **主從式版面**：左樹（可隱藏）＋右詳細；視窗 <860px 自動上下堆疊。
- **樹狀操作**：新增頂層／子節點、刪除（按兩下確認）、收合、選取。
- **雙擊節點名稱就地改名**（Enter／點空白處完成、Esc 取消）。關鍵修正：選取節點時只重繪右側詳細（`refreshDetail`），不重建整棵樹，雙擊才成立。
- **拖曳排序**：用左側六點握把拖曳；上緣＝前、下緣＝後、中間＝成為子節點；擋掉拖進自己子孫。
- **元件收攏鈕**：收攏後只留欄位名稱＋元件類型。
- 是否必填改 `req`（含「選擇性」條件）；可輸入字元類型改 `multi`（數字／英文／中文／符號）；驗證時機改 `choice`（即時／送出時／待確認）。
- Radio／Checkbox 拆成兩個獨立元件（Radio 單選、Checkbox 複選），移除「互斥或可複選」，改加「備註」。
- 每個元件（除「自訂備註」外）末尾都加了「備註」欄位。

## 6. 匯出格式

- **JSON**：`{meta, tree}`，每個節點附上算好的 `menuPath`。可回頭載入；**舊的平面 `screens` 格式也能自動轉成頂層節點**。
- **Markdown**：先輸出 └ 縮排的架構圖，再逐節點列「選單路徑＋已填欄位＋元件」。`req` 會顯示「選擇性（條件）」，`multi` 顯示選項串接，`choice` 顯示中文選項。

## 7. 驗證方式（重要背景）

Claude 這端**無法真的開瀏覽器預覽或執行互動**。做法是：抽出 `<script>` 用 `node --check` 驗語法，再用「最小假 DOM」在 Node 實際執行邏輯函式（進度、Markdown、樹搬移、normalize 等）比對輸出。**視覺與互動手感須由你在真實瀏覽器驗收**。
